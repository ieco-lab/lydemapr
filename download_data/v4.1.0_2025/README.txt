README for the folder download_data/v4.1.0_2025

The datasets contained here pertain to version 4.1.0 of the package lydemapr, published in July 2026 and containing data through 2025. This version contains all data included in version 4.0.0, with an additional `alpha_selection` table. It also includes the necessary functions to delineate the alphahull invasion boundary (ie `alphahull_sf()`, `map_alphahull()`, `sampling_effort()`, and `scale_selection()`). For details on the use of these functions, see the "Invaded Range" tab of https://ieco-lab.github.io/lydemapr/.

This folder contains a compressed version of the dataset in .csv format for ease of access.
The data can be freely downloaded in case the user prefers to access it through a different software than R.

Please use appropriate citations when using and distributing this data:
De Bona, S., L. Barringer, P. Kurtz, J. Losiewicz, G.R. Parra, & M.R. Helmus. lydemapr: an R package to track the spread of the invasive spotted lanternfly (*Lycorma delicatula*, White 1845) (Hemiptera, Fulgoridae) in the United States. NeoBiota 86: 151-168. [https://doi.org/10.3897/neobiota.86.101471](https://doi.org/10.3897/neobiota.86.101471)
